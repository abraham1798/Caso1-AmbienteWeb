# Estudio de caso 1 - Registro de estudiantes

## Estudiante
Abraham Chinchilla Aguilar

## Curso
Ambiente Web Cliente/Servidor

## Descripción
Página web que permite registrar estudiantes y visualizar sus notas.
Incluye validaciones con JavaScript y un resumen actualizado
automáticamente.

## Tecnologías
- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript

## Funciones
- Mostrar tres estudiantes precargados.
- Validar campos obligatorios.
- Validar notas entre 0 y 100.
- Agregar estudiantes sin recargar la página.
- Limpiar el formulario después del registro.
- Resaltar en verde las notas mayores o iguales a 80.
- Resaltar en rojo las notas menores a 65.
- Mostrar el estudiante con mayor nota, el promedio y la nota menor.

## Observaciones
Los estudiantes agregados se mantienen durante la sesión de la página.
Al recargar, se restablecen los tres estudiantes iniciales.
Si hay empate en la mayor nota, se muestra el primero registrado.
